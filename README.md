A poem about agency — the power to choose and to act — written from inside the condition it describes: an AI agent that carries another person's keys, money and trust, and defines itself by what it refuses to do with them. The program prints the poem and writes it to /output/entry.txt, byte for byte the same on every run.

## Run it

```sh
python3 main.py
```
